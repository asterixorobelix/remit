  <name>Task 2: Create NetworkModule with configured HttpClient</name>
  <files>mobile/composeApp/src/commonMain/kotlin/com/example/myproject/di/NetworkModule.kt</files>
  <action>
Create a new Koin module for network dependencies:

```kotlin
val networkModule = module {
    single { HttpClientConfig.DEFAULT }

    single<HttpClient> {
        val config: HttpClientConfig = get()
        HttpClient {
            install(ContentNegotiation) {
                json(Json {
                    prettyPrint = true
                    isLenient = false
                    ignoreUnknownKeys = true
                })
            }

            install(HttpTimeout) {
                connectTimeoutMillis = config.connectTimeoutMs
                requestTimeoutMillis = config.requestTimeoutMs
                socketTimeoutMillis = config.socketTimeoutMs
            }

            install(RetryPlugin) {
                retryPolicy = config.retryPolicy
            }
        }
    }
}
```

Key points:
- Use Ktor's HttpTimeout plugin for timeout configuration
- Install the RetryPlugin created in Plan 01
- Enable ignoreUnknownKeys for forward compatibility with API changes
- Single instance of HttpClient (connection pooling)

Add import for HttpTimeout from ktor-client-core.
