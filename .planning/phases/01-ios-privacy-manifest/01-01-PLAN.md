<task type="auto">
  <name>Task 1: Create PrivacyInfo.xcprivacy file</name>
  <files>mobile/iosApp/iosApp/PrivacyInfo.xcprivacy</files>
  <action>
Create the privacy manifest file with the following declarations:

1. **NSPrivacyAccessedAPICategoryFileTimestamp** with reason code **0A2A.1**
   - Required because Compose Multiplatform uses `stat`/`fstat` internally for file operations
   - Reason 0A2A.1 is for SDK wrapper usage (not app-specific file access)

2. **NSPrivacyAccessedAPICategoryUserDefaults** with reason code **CA92.1**
   - Required if app uses UserDefaults for settings/preferences
   - Reason CA92.1 is for app-only access (not shared via App Groups)

Include XML comments explaining why each API is declared for future maintainers.

Set NSPrivacyTracking to false (no user tracking).
Set NSPrivacyTrackingDomains to empty array.
Set NSPrivacyCollectedDataTypes to empty array.

Use proper XML plist format with DOCTYPE declaration.
  </action>
  <verify>File exists at mobile/iosApp/iosApp/PrivacyInfo.xcprivacy and is valid XML (xmllint --noout)</verify>
  <done>PrivacyInfo.xcprivacy created with FileTimestamp (0A2A.1) and UserDefaults (CA92.1) declarations</done>
</task>

<task type="auto">
  <name>Task 2: Add PrivacyInfo.xcprivacy to Xcode project</name>
  <files>mobile/iosApp/iosApp.xcodeproj/project.pbxproj</files>
  <action>
Modify the Xcode project file to include PrivacyInfo.xcprivacy in the build.

1. Add file reference to PBXFileReference section with:
   - lastKnownFileType = text.xml
   - path = PrivacyInfo.xcprivacy
   - sourceTree = "<group>"

2. Add to PBXGroup children (same group as Info.plist)

3. Add to PBXResourcesBuildPhase files section for the iosApp target
   - This is CRITICAL - without this, the file won't be included in the app bundle

Generate a unique 24-character hex ID for each reference (use format similar to existing IDs in the file).

IMPORTANT: Preserve exact formatting of project.pbxproj - Xcode is sensitive to whitespace and structure.
  </action>
  <verify>grep -q "PrivacyInfo.xcprivacy" mobile/iosApp/iosApp.xcodeproj/project.pbxproj</verify>
  <done>PrivacyInfo.xcprivacy added to Xcode project with correct target membership</done>
</task>
