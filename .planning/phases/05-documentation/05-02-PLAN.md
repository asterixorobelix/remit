# FEATURE_SETUP.md - Feature Configuration Guide

## Overview
Brief intro explaining this is a guide for enabling optional features in the template.

## Table of Contents
- Firebase Setup (Crashlytics + Analytics)
- Feature Flags
- Network Configuration
- Push Notifications (Coming Soon placeholder)
- Authentication (Coming Soon placeholder)

## Firebase Setup (Crashlytics + Analytics)
- Brief description of what Firebase provides
- Reference existing FIREBASE_SETUP.md for detailed instructions
- Quick checklist:
  - [ ] Create Firebase project
  - [ ] Add google-services.json for Android
  - [ ] Add GoogleService-Info.plist for iOS (optional)
  - [ ] Enable Crashlytics in Firebase console

## Feature Flags
Document the feature flags system from Phase 3:
- Explain the three implementations:
  - FeatureFlags interface (contract)
  - LocalFeatureFlags (default implementation with code-level defaults)
  - DebugFeatureFlags (decorator for runtime overrides in debug builds)
- How to add a new feature flag:
  1. Add property to FeatureFlags interface with default
  2. Add DEFAULT_* constant to companion object
  3. Override in LocalFeatureFlags if needed
  4. Use via Koin injection in ViewModels/Composables
- Example usage code snippet
- Note: Firebase Remote Config integration is deferred to v2

## Network Configuration
Document network resilience from Phase 4:
- HttpClientConfig: how to customize timeouts
  - connectTimeoutMs, requestTimeoutMs, socketTimeoutMs defaults
- RetryPolicy: how to customize retry behavior
  - maxRetries, initialDelayMs, maxDelayMs, backoffMultiplier, useJitter
- NetworkResult sealed class: Success, Error, Loading states
- How to modify defaults in NetworkModule.kt
- Example: Changing timeout for slow APIs

## Analytics
- Explain Analytics interface and AnalyticsEvents/AnalyticsParams constants
- How to log custom events
- How to track screen views
- Note: Uses Firebase Analytics when configured, falls back to logging

## Crash Reporting
- Explain CrashLogger interface
- How to log non-fatal exceptions
- How to add custom keys for debugging
- Note: Uses Firebase Crashlytics when configured, falls back to logging

## Coming Soon
Placeholder sections for v2 features:
- Push Notifications (FCM + APNs)
- Authentication (Firebase Auth)
- In-App Purchases

Keep each section concise with code examples. Target: developers can enable a feature in 5-10 minutes by following the guide.
