## Assets Checklist

### Required Graphics
- [ ] App icon source (SVG, 1024x1024 minimum)
- [ ] Feature graphic (1024x500 PNG) - Google Play
- [ ] App Store icon (1024x1024 PNG) - iOS
- [ ] Phone screenshots (minimum 2, recommended 4-8)
- [ ] Tablet screenshots (optional but recommended)

### Generating Assets

**From SVG source:**
```bash
# Feature graphic
magick feature_graphic.svg -resize 1024x500 feature_graphic.png

# App Store icon
magick app_icon_source.svg -resize 1024x1024 appstore_icon_1024.png

# Screenshots (if using SVG mockups)
magick screenshot_template.svg -resize 1284x2778 screenshot_1.png
```

### Screenshot Dimensions

**Google Play:**
- Phone: 16:9 or 9:16 aspect ratio, min 320px, max 3840px per side
- 7" Tablet: 16:9 aspect ratio (optional)
- 10" Tablet: 16:9 aspect ratio (optional)

**App Store:**
- 6.7" (iPhone 15 Pro Max): 1290x2796
- 6.5" (iPhone 14 Plus): 1284x2778
- 5.5" (iPhone 8 Plus): 1242x2208
- iPad Pro 12.9" (6th gen): 2048x2732
- iPad Pro 12.9" (2nd gen): 2048x2732
